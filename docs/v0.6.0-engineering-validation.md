# v0.6.0 engineering validation

This record distinguishes three kinds of evidence: runtime regression tests,
retrieval results on the fixed engineering development workload, and comparisons
with explicitly configured upstream components. No coding LLM, independent
holdout or production productivity study is included. The current results and
their complete original outputs are retained under
[`benchmarks/reports/v0.6.0-engineering`](../benchmarks/reports/v0.6.0-engineering/).

## Measured outcomes

The full [hosted matrix](../benchmarks/reports/v0.6.0-engineering/hosted/memory-systems/report.json)
completed all seven backends with no execution, source-validation, budget or
repeat-stability failures. The independent
[audit](../benchmarks/reports/v0.6.0-engineering/audit.json) passed **116,693 checks
with zero failures**, including every recomputed score and all **320 complete
response pairs** between the original and expanded component harnesses.
The same-runtime default verifier passed all 80 cases.

## What changed in the runtime

Current-evidence ranking previously allowed a newer maintenance mention to
inherit the ranking position of an actual configuration declaration when their
matched query terms were identical. At a small whole-block budget, intervening
maintenance pages could consume space before a replacement decision fitted.
The release now distinguishes explicit declarations of comparable fields from
other mentions inside the same bounded candidate pool.

The rule requires the same task and remaining query facets. It preserves field
word boundaries and dot-qualified segments, retains clear naming aliases and
limited prose updates, and never uses the assigned value in its key or score.
Statements exchange their existing relevance slots; unclassified evidence is
not deleted. Historical/relevance queries and recognized event-count or timeline
queries retain their previous paths. Optional semantic candidate fusion applies
the same rule.

Source coordinates alone do not prove that a page contains a complete turn:
the first page of a continuation can also have zero-based coordinates. Before
using a declaration hint, the implementation verifies equality between page
content and the designated original turn inside the existing SQLite read
snapshot. Recognized code blocks, quoted logs, inline code, questions and
conditional examples do not establish declarations. Quote state survives
sentence and line breaks. Qualified-name delimiters also prevent repeated
suffix scanning of long identifiers.

Field analysis is limited to 64 query-relevant identities and 64,000 characters
per candidate. Over-limit or ambiguous input retains the existing candidate
path and supplies diagnostic information. The heuristic does not understand all
natural-language negation, rollback or authority. It does not guarantee that a
small context budget contains every relevant statement.

The release keeps schema 4, original text, page addresses, source coordinates,
scope filters and both context-budget mechanisms. Recall cache version 16
isolates the changed ordering. Detailed responses expose
`temporal.declaration_ordering`; compact MCP output keeps its prior projection.

## Fixed workload and separate packing tracks

The unchanged workload has eight projects, four algorithm families, six
chronological checkpoints and 80 questions. There are 72 answerable questions,
80 required source spans, 48 fixed-policy cases and eight missing-evidence
questions. Families cover negative-edge shortest paths, Top-k ties, training
data splits and fully masked softmax. Source-session replacement and project
isolation remain part of the workload. Each checkpoint exposes only its
previously ingested history.

The native track runs Book, scoped flat FTS, recent history and no memory with
the existing evaluator. Native Book may choose source-authenticated excerpts.
The component track gives all engines the same complete original pages, project
scope and top-five limit, then applies the unchanged common whole-block packer.
An oversized block is skipped instead of truncated. Both tracks retain
1,200- and 2,400-character budgets, including citation headings and separators.
Character limits do not cap the complete protocol JSON or model tokens.

External indexes are rebuilt from the currently visible page snapshot at each
checkpoint. Source replacement therefore tests retrieval from the updated
snapshot, not each product's own incremental update/delete lifecycle. The new
matrix has 560 query/backend pairs and 1,680 native calls across three repeats;
its two budgets reuse those candidates to produce 1,120 packed outputs.

Three repeats provide timing and stability observations. Each question is scored
once per backend and budget, so repeats are not additional quality cases.
The fixed consumer extracts recorded policies and executes handwritten algorithm
variants; its pass rate is not generated-code accuracy. Quality comparisons
between the tracks would mix packing strategies and are not made here.

model-quality confirmations. Mem0 retains its native threshold and rerank

response is supplied. Book and billion retain additional native indexed
metadata; common page bodies do not imply identical indexed features.

the official model archive and every extracted model file. Workers receive an
allowlisted environment, task-specific configuration/cache/storage paths and
no inherited provider credentials. Measured Python workers reject INET
connections after public artifact preparation. The normal Book package does
not acquire these optional comparison dependencies or model weights.

## Independent result checks

[`scripts/audit_memory_systems.py`](../scripts/audit_memory_systems.py) reads the
retained outputs without running retrieval. It verifies the complete matrix,
native source mappings, exact query/scope/chronological inputs, repeated native
responses, both budgets and every recomputed score. It also rebuilds each common
context from the native candidate IDs and original pages.

The unchanged two-component evaluator is retained as a separate control. The
audit checks 320 complete response pairs: 80 questions, two budgets and Book
plus billion, comparing that control with the expanded matrix. Equal scores
alone would be insufficient; every packed response field must agree.
The audit separately retains paired changes against the previous source,
category results, missing-evidence behavior and each timing boundary.

The audit records every input hash and rejects duplicate records, changed
source/query data, inconsistent summaries, unstable output, type drift and
attempted output overwrites. Its own eleven contract tests include intentional
failures. A read-only validation of the retained prior native/component reports
performed 25,576 checks without a failure; that validates audit compatibility,
not the new release's quality.

## Interpretation limits

These authored development cases do not establish a universal ranking of memory systems.
Scores establish recovery of specified evidence in the stated configuration,
not the truth or final authority of every archived statement. A fixed-policy
pass can coexist with incomplete multi-span evidence because its denominator
and required behavior differ from the complete-evidence metric.

`stale_only` specifically counts marked obsolete evidence without the required
span. Zero stale-only cases does not mean zero wrong policies or correct
historical lookup; billion's eight historical-decision misses illustrate that
distinction. The three shared-MiniLM configurations have identical aggregate
quality counts here, but their complete responses are not all byte-identical.

Related context for a missing-evidence question is not a validated answer or
abstention decision. Queries still need source inspection when evidence is
missing or contradictory. Latency includes only the explicitly recorded
interfaces: Python/Bun IPC, model preparation, indexing, actual query embedding
and common packing have different boundaries. There is no whole-product speed
ratio or total model-cost claim. Resource use, unseen real task success,
long-running update behavior and generated-code correctness need separate
experiments. Unmeasured systems in the
[fourteen-family review](open-source-memory-comparison.md) are not assigned or
ranked by fabricated scores.
