# Unselected I + T1 integration source

This branch is a source-integration checkpoint, not an accepted performance or
quality release. It executes no benchmark or fresh-question selection.

## Exact parents and retained behavior

The sole Git parent is I's final Python 3.10 fixture-repair commit
`21b6f4196e42167f8532feafc30457f5684d25cf`. Its runtime is the unchanged I runtime
originally frozen at `505e84282ae6ba6cc31eda4bc6b3f658c983bcce`. All I tests,
negative controls, earlier CI failures and receipts remain in the tree.

The feature donor is T1's previously tested CLI/MCP integration source
`b34925804b4d953b4a783e9d431bda4c31c90ebd`. Its complete title-reference module,
CLI/MCP changes and artificial source/interface tests are copied without
feature changes. The existing indexed-reference schema fixture retains every
old field while admitting exactly the already registered optional boolean.

The store edit adds T1's argument validation, preconditions, option-specific
cache identity, full-pool hop and provenance. Active T1 calls disable native
tuple materialization and canonical prefix materialization, retaining the
complete lexical order and original Row path. Default and inactive calls keep
I's path. An active call does not invalidate the native connection certificate
for a subsequent default call.

G's native connection/cursor/shape certificates and all custom fallbacks remain.
I's fixed 512-entry native statement cache remains. E's
`ranked_rows.clear()`, F's overlap change and H's pager change are not added.
All runtime files except store.py, cli.py, mcp_server.py and the new
title_reference.py retain their exact I blobs. Reversing the eight recorded
store edits restores the exact original I store text; reversing the CLI/MCP
feature additions likewise restores I bytes.

## Verification scope

The inherited T1 tests cover source projection, scope, ambiguity, bounded title
matching, default cache/payload parity, complete-pool promotion, concurrency,
both tokenizers and strict CLI/MCP boolean/provenance contracts. New
`tests/test_title_reference_native_integration.py` checks actual native versus
active/full-row behavior, connection/factory preservation across mode changes,
and complete-payload parity under a custom Row-producing factory. Its data is
invented. These checks do not make a corpus-quality or speed claim.

The repository's unchanged hosted Tests workflow will verify this exact
integration commit. No tests are claimed to have passed before that run.
A version accepted for release still needs its own exact runtime hash, frozen
interface certificate, applicable formal performance, historical lexical/Q2
compatibility, fresh native/component validation and independent review.

The original round-five numeric/resource/payload/no-replay gates and the
registered T1 scopes remain in force. No I speed percentage or T1 quality
percentage is transferred to this combined runtime.
