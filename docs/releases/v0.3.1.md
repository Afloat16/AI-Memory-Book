# v0.3.1 candidate — faster scoped recall with unchanged evidence

**Status: prepared candidate.** These notes describe the version being validated
for delivery; they do not announce a published GitHub tag or release.
The last published version remains v0.3.0 until the separate publication
workflow runs.

## What changes

The default lexical path now uses a project rowid envelope to avoid scanning
unrelated FTS candidates when the project occupies a selective part of the
archive. Bounds are read inside the existing transaction and are not cached.
Explicit project/chapter/session filters still run before the 96-candidate
limit. Global BM25 statistics, deterministic ties, original text, source spans,
citations, limits and response fields are preserved.

Session-scoped calls and interleaved/nonselective project layouts retain the
previous path. Tests cover independent writers, deletes/relinks, Unicode and
the candidate limit. No database migration or new core dependency is needed.
The optional ONNX model initialization disables telemetry; lexical retrieval
still performs zero model calls. Q2 remains opt-in.

## Measured gains against v0.3.0

The registered experiment uses four balanced ABBA rounds, 16 workers and
47,320 actual calls across ten corpus/configuration cells.

| Measurement | v0.3.0 | v0.3.1 candidate | Change |
|---|---:|---:|---:|
| Public corpus native recall p95, 4,000 characters | 5.054 ms | 3.737 ms | −26.05% |
| Public corpus actual MCP p95, 4,000 characters | 7.409 ms | 5.937 ms | −19.87% |
| Geometric mean of the ten pooled p95 ratios | — | — | 11.36% improvement |
| Synthetic 512-token native p95 | 21.052 ms | 21.079 ms | +0.13% |

Complete non-timing payloads and source/index contents remain unchanged.
No pooled p50 or p95 cell regresses by more than 5%.
The [optimization report](../optimization-round3.md) retains all ten cells,
individual rounds, resources and the unchanged original report.

Empty-database opening in the original experiment increased **4.838 ms
(+14.04%)**. The original automatic acceptance remains false. A separate
[resource review](../round3-startup-resource-review.md) accepts the disclosed
cost after checking unchanged startup code and 80 new diagnostic samples.
Those diagnostics do not replace the original observation or establish the
historical operating-system cause.

## New competitor evidence

Candidate, evaluator, upstream source/binary/model identities and selection
rules were committed before selecting 256 additional HotpotQA questions.
The selection has zero overlap with the prior 384 IDs. All ten stages in
[run 43267797247](https://github.com/Afloat16/AI-Memory-Book/actions/runs/43267797247)
completed: 4,608 native calls and 4,608 component searches, with 1,280 additional
ai-memory page reads accounted separately.

Common source pages, top five, whole-page packing and a 1,024
`cl100k_base` token cap yield:

| Retrieval component | Evidence recall | Complete evidence | Search roundtrip p95 |
|---|---:|---:|---:|
| Book default lexical | 76.28% | 52.34% | 2.784 ms |
| Book optional Q2 | 76.77% | 54.69% | 11.226 ms |
| claude-mem 15.18.1 FTS | 70.68% | 45.31% | 22.826 ms |
| ai-memory v3.4.5 local hybrid | 77.27% | 55.86% | 27.545 ms |
| billion-context 9674cfa search kernel | 78.91% | 58.20% | 1.010 ms |

Default Book completes 18 more questions than claude-mem FTS (**+7.03 percentage
points**) and has lower measured latency. ai-memory's completeness is higher;
billion-context's kernel leads the displayed quality and latency metrics.
These interfaces perform different amounts of work, so the table does not
establish whole-product speed ratios. Quality uses one result per question;
three timing repetitions and six offline projections do not increase that
sample count. See [every configuration, cost and loss](../round3-comparison.md).

The comparison also verifies full default payload equivalence against v0.3.0:
**1,536 native pairs and 768 component pairs**, removing timing only. There
are no source, scope or budget failures.

## Decisions kept visible

- **Project-statistics research was rejected.** All 8,082 original calls from
  eight workers were recovered and audited with zero new measurements. Gains
  on one old cohort did not compensate for losses elsewhere under the frozen
  screen. That runtime is not in this candidate or the new comparison.
- **Q2 is optional.** On the new native 512-token settings, it loses six complete
  questions under each tokenizer. At 1,024/2,048 it gains six. Its pinned local
  model totals 127.5 MB; this 3,896-page semantic index took about 110 seconds
  to build. Runtime/model/index costs are reported separately.
- **Evidence retrieval has limits.** This is a new selection from the same
  public HotpotQA source, all answerable. It does not establish answer accuracy,
  abstention, hallucination rate or cross-domain generalization. The selected
  questions now serve as regression evidence.

## Installation and upgrade

Use the artifact from a successful
[package preparation run](https://github.com/Afloat16/AI-Memory-Book/actions/workflows/release-prepare.yml).
The delivery PR links the run and artifact for its exact final commit.
Extract the artifact, enter the directory containing the installer and wheel,
and run:

```bash
python3 install.py --source ./ai_memory_book-0.3.1-py3-none-any.whl
```

On Windows replace `python3` with `py -3`. Use the printed launcher path if
necessary. Verify `memory-book --version` prints `0.3.1`, then rerun
`memory-book setup` with the same client and capture options as the existing
installation. The managed installer retains the archive and previous
environment. An [exact-source route](../deployment.md#try-the-v031-candidate-before-publication)
is available before release publication.

The seven prepared assets are the universal wheel, source archive, three
installers, `release-manifest.json` and `SHA256SUMS`. They exclude benchmark
archives, models and databases. Preparation checks wheel and sdist in separate
clean environments and installs the produced wheel with default MCP/client
extras. Final delivery requires all nine normal CI jobs and the independent
read-only evidence audit on the exact integrated source.
