# v0.8.1 — further native text acceleration

This release moves identifier-alias construction and literal excerpt occurrence
collection into the existing optional C extension. Its performance comparison
starts from the already-native v0.8.0 release. Python retains normalization,
retrieval decisions, public interfaces and the portability fallback.

## Changes and compatibility

- Preserve identifier component order, repeated index terms, compact query
  aliases, per-run duplicate checks and qualified-name boundaries.
- Preserve nonoverlapping literal matches, the 40-match limit per term, exact
  Unicode code-point coordinates, empty matches and existing mapping errors.
  Window construction, floating-point scoring and final excerpts stay in Python.
- Retain supported dynamic helper overrides and unusual argument types through
  the Python reference. The index guard runs after whole-string tokenization
  so helper mutations retain their original order.
- Keep schema 4, SQL, FTS indexes, ranking, project scope, source/page IDs,
  segmentation, character/token budgets and cache policy unchanged. An existing
  schema-4 archive needs no migration.

## Incremental performance

The frozen experiment uses four balanced A/B rounds, three passes per worker,
two cohorts and both direct recall and actual official-SDK stdio MCP. All
**113,568 calls / 56,784 pairs** pass the recorded complete-output, archive,
source-coordinate, scope and budget comparisons.

| Dataset | Surface, 2400-character budget | v0.8.0 p95 | v0.8.1 p95 | Latency reduction |
|---|---|---:|---:|---:|
| synthetic61 | Direct recall | 8.774 ms | 8.506 ms | **3.06%** |
| synthetic61 | Real SDK MCP | 10.463 ms | 10.200 ms | **2.51%** |
| public1015 | Direct recall | 3.651 ms | 3.472 ms | **4.90%** |
| public1015 | Real SDK MCP | 5.222 ms | 5.016 ms | **3.95%** |

Each primary cell improves in every paired round. Fresh synthetic ingestion
improves **9.58%**; public ingestion is essentially unchanged. At the separately
tested 1024-token limit, synthetic p95 improves 0.47%/0.61%, while public direct
recall is flat and public MCP p95 regresses **0.33%**, approximately **0.015 ms**.
Some secondary rounds regress; no universal token-budget speedup is claimed.

API import adds approximately 0.21–0.33 ms and default MCP initialization adds
1.42–1.62 ms. New database setup adds approximately 0.16–0.27 ms; these resource
figures are medians of four workers per side. Memory remains approximately
unchanged and checkpointed database
sizes are identical. The complete
[validation report](../native-incremental-validation.md) retains all eight
configurations, round-level results and resource costs.

Measurements cover one hosted Intel Xeon/CPython 3.12 environment, with no
query-result cache hits and normal SQLite/OS caches. Model generation is
excluded. The earlier Python-to-native experiment used a different AMD host;
its absolute timings and percentages are separate evidence. These existing
datasets establish compatibility and measured performance, not new retrieval
quality, whole-product latency or cross-platform speed guarantees.

## Installation and upgrade

Use the pinned v0.8.1 installer in the [deployment guide](../deployment.md).
It selects and verifies a compatible native wheel using its isolated Python
environment's own compatibility tags. The matrix covers CPython 3.10–3.15 with
the GIL on Linux x86-64/AArch64, macOS Intel/Apple Silicon and Windows x64.
Unsupported environments retain the compiler-free Python fallback.

Check the installed interpreter reported by the installer:

```bash
python -I -c "import memory_book; from memory_book._text_backend import BACKEND_NAME; print(memory_book.__version__, BACKEND_NAME)"
```

A compatible native installation prints `0.8.1 native`.
`MEMORY_BOOK_TEXT_BACKEND=python` selects the reference; `native` requires the
extension and fails if unavailable; `auto` chooses the available implementation.
Source builds can require a compiler with `MEMORY_BOOK_BUILD_NATIVE=1` or select
the portable fallback with `0`.

Preserve existing archive/configuration paths, refresh client and service
launchers, and restart them after upgrading. Earlier schemas should follow the
existing backup/migration procedure. Defaults remain 2400 characters and five
results, with optional exact token limits. The MIT license is unchanged.
