## Accepted interface and implementation

Previous remote checkpoint: `bb4d92b524b4be0fddfc05b509a181371db9cff7`.

- `recall(..., all_projects=False)` resolves an explicit project, an exact
  chapter's project or the sole project in an archive. Multiple books without
  that identity raise before retrieval; intentional global calls must opt in
  with `all_projects=True`. A session ID or display name never guesses a book.
  Empty scope strings are invalid, including at HTTP boundaries. Existing
  explicit project retrieval and candidate ranking remain the regression path.
- `search_directory(query, project, offset=0, limit=20)` searches title,
  question and task/session directory fields only, groups matching continuation
  pages into section entries before pagination, and returns scoped metadata,
  source addresses and breadcrumbs rather than full page text.
- `chapter`, `section` and `read` accept an optional exact `project` guard.
  Directory responses use one SQLite read snapshot, preserving caller-owned
  transactions. Explicit correct IDs keep their existing source addresses.
- `read_turn(project, session_id, turn_index, offset=0, limit=12000,
  source_hash=None)` provides complete normalized original-turn pagination.
  Return `source_hash` on page/source reads and carry it into continuation calls
  to reject session replacement between chunks. Original question metadata is
  bounded to 240 characters. Source character coordinates and message indices
  remain available. The chunk limit applies to content, not the entire JSON.
- No archive schema migration; recall cache version becomes 17.

Core tests are in `tests/test_book_navigation.py`. The first new fixture used
an invalid 120-character page-size setting; it was corrected to the supported
150-character setting before the 72-test run. No quality matrix has run.
The saved [development test log](../benchmarks/reports/v0.7.0-engineering/development/navigation-core-stage1.log.gz)
is a development check, not the final release gate.

The new fixed cohort contains 80 cases across eight exact, deliberately similar
project IDs and four checkpoints: 64 answerable cases, 72 required spans, forty
fixed-policy checks, eight globally absent facts and eight facts present only
in a neighboring project. Every project has the same display name. Dataset

Thirty-two metadata-only directory requests and separate source/scope contracts

or generated-code accuracy claim is planned.
