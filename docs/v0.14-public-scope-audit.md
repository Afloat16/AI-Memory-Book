# Public-source holdout: additional declaration-scope audit

The original public-source holdout v2 remains frozen at
`2a73098f492652da5bd3c072e2ca5590acfc61cb`. Its metric authenticates a gold
quote in the specified project and source file. Several files repeat identical
constructor literals in distinct classes or helper methods. For example,
HTTPX has the same `http2` default in Client, AsyncClient and helper signatures.
A file-level match alone cannot establish which class declaration was returned.

This additional **post-protocol audit** preserves every original v2 result and
adds a stricter metric. Its bindings were authored exclusively from the pinned
source AST and the existing question's named class/field, before the auditor
opened any response artifact. The runtime implementers did not inspect these
sources. No retrieval is executed or repeated by this audit.

The frozen supplement covers all 48 original questions and all 44 required
evidence spans. It binds each span to one exact declaration:

- A direct module assignment for a named module constant.
- A direct attribute assignment of the named class.
- The named constructor parameter of the named class.
- The named `self` assignment inside the named initializer, excluding nested
  functions and classes.

Each binding records the original source hash, AST scope, line, source offsets,
unchanged chunk index and exact turn coordinates of the required quote. AST
UTF-8 byte columns are converted to Unicode code-point offsets. The chunk's
`USER: ` prefix adds six code points. Scope credit requires the authenticated
returned source coordinates to include that exact declaration; a same-value
literal in another class, another method, or another position in the same
chunk does not qualify.

`benchmarks/experiments/v014-public-scope-audit.json` is the frozen allowed
coordinate supplement. The auditor first rederives it from the pinned source
and verifies its own explicit commit. Only then does it open original reports
and response archives. It reuses the frozen v2 source verifier before assigning
scope credit, verifies each saved v2 score, and retains original file-level
and stricter scores side by side. Missing and failed original cells remain
visible. A stricter matched-span count can never exceed the original count.

```bash
python benchmarks/v014_public_scope_audit.py audit \
  --audit-commit EXACT_SCOPE_AUDIT_COMMIT \
  --responses /absolute/path/to/original-holdout-arm \
  --output /absolute/path/to/new-scope-audit.json
```

When the audit and holdout code are in different checkouts, pass
`--holdout-root /absolute/path/to/holdout-protocol-tree`. The original holdout
files must still match their v2 commit. The nine integrity tests use constructed
AST/source examples and frozen coordinate metadata only; they do not inspect
holdout responses or call the retriever.

This is a stricter evidence-scope measurement, not proof of complete Python
runtime semantics, global absence, authoritative configuration, or LLM answer
accuracy. Keep the original v2 metric, this post-protocol metric, and any later
runtime evaluation attempts distinctly labeled.
