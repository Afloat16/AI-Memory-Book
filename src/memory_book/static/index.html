项目是一本书，任务是一个章节
同一个 project 的会话收在一本书里。给相关会话相同的 task_id，就能把跨会话的同一任务归入一个章节；原始会话和问答出处仍然保留。
直接提问，也可以沿目录阅读
在上方输入问题，即可返回相关记忆页。先选择一个项目，可以避免取到其他项目里的同名内容。点击结果中的“阅读原文”，查看原始会话片段。
阅读预算，让每次回想有所取舍
预算限制返回上下文的字符数，包含引用信息；显示的 token 数只是估算。系统按词语匹配查找，换个关键词可能找到更多内容。返回片段是历史证据，不代表今天仍然有效。
从一次会话开始
导入包含 project、session_id 和 messages 的 JSON。可以先点击“填入示例”体验；示例是虚构的演示会话。
